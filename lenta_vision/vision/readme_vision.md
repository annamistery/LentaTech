
# Модуль vision для распознавания ценников в супермаркете

## Описание
Модуль `vision` предназначен для обработки и анализа изображений ценников в супермаркете. Он включает функции для определения размытости изображения, распознавания цвета ценника, извлечения данных с помощью нейросети, а также поиска штрихкодов и QR-кодов.

## Основные возможности:
- **Проверка резкости изображения** — определяет, не является ли изображение размытым.
- **Определение цвета ценника** — анализирует цвет ценника для последующей обработки.
- **Извлечение данных с изображения** — использует локальную мультимодальную модель на базе qwen (через `LlamaCPPClient`) для извлечения текстовой информации.
- **Поиск штрихкодов и QR-кодов** — находит и извлекает информацию из штрихкодов и QR-кодов.

## Используемые библиотеки:
- **OpenCV (cv2)** — для обработки изображений.
- **NumPy (np)** — для работы с массивами данных.
- **Llama-cpp-python** — для работы с нейросетью и извлечения данных с изображения.
- **Pillow** — для работы с изображениями в различных форматах.
- **Pyzbar 0.1.9** — для распознавания штрихкодов и QR-кодов.
- **Logging** — для логирования событий и ошибок.

## Структура модуля:
- `cpp_llm/` — содержит модули для работы с llama-cpp-python.
- `modules/` — содержит функции для обработки изображений (например, проверка размытости, определение цвета).
- `qr_bar_code/` — содержит модули для распознавания штрихкодов и QR-кодов.
- `utils/` — вспомогательные функции (например, преобразование изображений в base64, построение промптов).
- `vision_main.py` — главный файл, в котором реализован конвейер обработки изображения.

## Установка зависимостей:
Для установки необходимых библиотек используйте команду:
```
bash
pip install -r requirements.txt
```
Если для работы нужны какие то модели - ссылки для скачивания есть в файлах `models_find.md`

## Использование:

Для запуска модуля используйте следующий код:
```
python
import cv2
from vision.vision_main import vision_main

# Загрузите изображение
img_bgr = cv2.imread("path_to_image.jpg")
### Запуск сервера LLM 
python3 -m llama_cpp.server   --config_file server_config.json

# Настройки 

config_dict = {
"min_blur_score": 6.0,
"color_threshold": 0.25,
"llm_base_url": "http://localhost:8000/v1",
"prompt_path": "path_to_prompt.yaml",
"upscale_fx": 3
}

# Запуск обработки
result = vision_main(img_bgr, config_dict)
print(result)
